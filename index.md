# AI Tools for Software Engineers
### A companion guide for SER375 / CSC575 — AI-Driven Software Engineering

Welcome! This site pulls together, in one place, everything you need to get comfortable with the AI tools and concepts used throughout this course — no prior AI background assumed. Each page is a self-contained, guided reading with plain-language explanations, diagrams, worked examples, and hands-on exercises.

## Why this exists

Across the semester you'll use generative AI for almost every phase of the SDLC: drafting requirements, designing architecture, generating and reviewing code, writing tests, and producing documentation. Rather than learning these tools by trial and error mid-assignment, work through the four guides below **in order** before your first project milestone. Together they take you from "what is a prompt" to "how do I direct an AI coding agent inside a real repository."

## How to use this site

- Read each page top to bottom the first time — later pages assume you know the vocabulary from earlier ones.
- Every page ends with **Try It Yourself** exercises. Do them — reading about prompting is not the same skill as doing it.
- Every page also ends with **Further Reading**, linking to the official documentation for the tools mentioned. Bookmark those; they update faster than any course material can.
- Keep a running **prompt log** (a plain text or Markdown file) as you go. You'll want it for your capstone project, and several exercises ask you to submit it.

## A note on AI tool use and academic integrity

Using AI tools well is a required skill in this course, not a shortcut around learning. You are expected to understand, verify, and be able to explain everything you submit — whether you wrote it yourself or an AI drafted the first version. When in doubt, keep your prompt log and be ready to walk through your reasoning.
